## Unlock

Verified by hand by the owner of the system on 2026-09-23: locked the screen,
entered the password, the password was accepted and the session came back.

A person watching the whole screen is a stronger check than a script reading a
return code. It is also corroborated by the logs of that boot (20:44:50) -
/var/log/lightdm/lightdm.log, times relative to LightDM's start:

    [+1851.48s] Launching process 3937: /usr/bin/X -core :1 ... vt8 -novtswitch
    [+1860.12s] Authenticate result for user mike: Success
    [+1860.14s] Unlocking login1 session 1

and the journal:

    21:16:30 systemd-logind[853]: Removed session c1.

The greeter was started on :1, authentication succeeded, LightDM unlocked the
user's logind session, and the greeter session c1 was closed. The password
itself appears nowhere in this evidence and is not needed for it.
