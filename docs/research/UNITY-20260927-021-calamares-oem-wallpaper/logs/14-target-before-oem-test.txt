## consequence
The OEM environment's basicwallpaper is copied into the target at OEM install time from the
installer medium's oemconfig.tar.gz. It is not managed by dpkg on the installed system, and the
installed system has no calamares-settings package. An apt upgrade inside the installed OEM-ready
disk cannot replace /usr/bin/basicwallpaper; the +unity2 fix reaches an OEM machine only when the
OEM install runs from a medium that carries calamares-settings-ubuntu-unity 1:26.04.12+unity2.
