===== reading
- One legacy query per sender at any time; a reopening within 2 s of CloseQuery keeps its path (query/11 for
  "о" -> "он" -> "оно"), a reopening after more than 2 s gets a new one (query/10 -> query/11).
- Enter: ExecuteQuery releases the query, the CloseQuery that Unity sends right after it finds no legacy
  query for the sender and changes nothing (CloseQueryWithoutLegacyQueryAddsNothing); no query objects left.
